Blender Python小白向入门学习日志

2026年7月 · 研究中

Python Blender脚本 入门学习 零基础

学习背景

此前在3ds Max中开发了资产质检和减面插件，但考虑到Blender的开源特性、活跃的社区生态以及与AI工具链的良好兼容性，决定开始学习Blender Python脚本开发，期望将来能将之前的功能复刻到Blender平台上。

目前学习资源主要来自B站和YouTube等平台，正在进行基础知识的积累。

学习目标

长期目标是基于Blender Python API，实现三维资产的自动化处理流程，具体目标如下：

  • 1. 模型批量导入与统计：批量读取FBX、OBJ等格式模型，自动统计顶点数、三角面数、四边面数，检测破面情况；
  • 2. 自动减面处理：基于Blender内置的Decimate修改器，实现批量减面，支持设置减面率；
  • 3. 材质与UV处理：批量处理材质和UV，确保贴图正确性；
  • 4. 批量导出与报表生成：自动导出处理后的模型，生成优化前后对比报表。

当前学习进展

目前尚处于初步探索阶段，主要专注于基础指令的学习：

  • 1. 了解Blender Python API的基本概念，知道bpy模块的存在；
  • 2. 学习如何在Blender中打开和运行Python脚本；
  • 3. 学习基础的对象操作指令，如创建、选择、删除对象；
  • 4. 学习如何访问和修改对象的基本属性；
  • 5. 正在通过B站教学视频进行基础知识的积累。

当前局限与学习难点

作为初学者，目前遇到的主要困难包括：

  • 1. API文档理解困难：Blender Python API文档内容庞大，对于初学者来说理解起来有一定难度；
  • 2. 代码调试困难：在Blender环境中调试Python代码比在普通IDE中更复杂；
  • 3. 三维概念与代码结合：将三维空间中的概念转化为代码逻辑需要一定的适应过程；
  • 4. 缺乏实际项目经验：目前主要学习基础指令，尚未进行实际项目的开发。

学习计划

后续学习计划如下：

  • 1. 继续基础学习：通过B站教学视频等资源，系统学习Blender Python API的基础知识；
  • 2. 实践小项目：尝试编写简单的脚本，如批量创建对象、修改材质等；
  • 3. 逐步实现功能：在掌握基础后，逐步实现模型导入、网格统计等功能；
  • 4. 参考现有代码：学习社区中优秀的Blender脚本案例，理解其实现思路。

后续将继续保持学习节奏，逐步积累经验，为将来实现资产质检、减面、批量导出等功能打下基础。
