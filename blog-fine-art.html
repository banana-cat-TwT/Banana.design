① 阶段概述

阶段概述

2022年9月美院入学后至大一暑假前，经历了一个方向极多、精力分散的阶段。主线是纯艺课程——综合材料绘画、人物立绘、动画、剪辑、拍摄、纪录片什么都做，同时还要学 Adobe InDesign 做书籍排版、了解纸张与封面材质并输出实体书，课余又用 After Effects 做 MG 动画和人物骨骼绑定动画。始终处于高强度输出 + 低获得感的状态。用原话讲：又累又忙又没意义，做的事情很杂很杂。

课余时间零散接触了多个数字工具：大一上自学Blender做了几个简单物品、高三玩过的ZBrush数字泥巴、以及大一下开始自学3ds Max和ZBrush的3D流程，但均因课业压力或浅尝辄止未能深入。

本篇为大一阶段（暑假前）的综合记录，涵盖纯艺课程与各类数字工具的初次接触。Live2D、Spine、VRoid Studio 等已有独立制作日志，不在本篇重复。

更早的起点：游戏梦想与高中萌芽

其实接触游戏和创作的种子早在幼儿园甚至更早的时候就埋下了。3岁的时候，因为奶奶特别喜欢玩麻将三缺一所以就教我玩电脑，4岁的时候家人教我用电脑和任天堂3DS游戏机、小掌机、主机Wii、跳舞毯等等。

幼儿园的时候特别崇拜做游戏的人，天天模仿游戏的UI界面、服装设计、人物设计。沉迷画画，画了很多纸质的怪兽卡片送给同学玩，有点类似桌游，并且画了好几本连环画故事书，除了游戏，还玩过可视化的少儿编程，算是幼儿启蒙了。

高中的时候在校内工作室干活，一下课就去工作室看B站的游戏解说、游戏演示，也会看3D建模教程。至于为什么会开始看这些？当时工作室来了个3D道具的单子，但工作室没有一个人会用3D，虽然最后单子退回去了，但也因此开始关注3D相关的东西。当然更主要的原因是从小就喜欢3A游戏，接触ZBrush玩数字泥巴也是在这个背景下开始的。

② 纯艺课程

综合材料绘画

并非仅限于传统"老三科"（素描、色彩、速写），而是使用十几种材料混合进行创作。

类别 可能涉及的材料/媒介
传统基底水彩、丙烯、油画颜料
干性材料炭笔、色粉、铅笔、马克笔
综合媒介拼贴纸材、织物、金属箔、石膏底料、指甲油、茶渍酒渍、口红等不用的化妆品
特殊技法厚涂堆叠、刮擦、泼洒、罩染、拿打火机烧画

特点：不拘于单一画种，强调材料实验与混合表现。这种综合材料的训练方式对后续数字美术中的材质理解和风格化表达有潜在影响——虽然当时未必意识到。

人物立绘

期间大量绘制人物立绘图，作为角色设计/人设的输出形式。

内容 说明
绘制形式全身角色立绘，用于展示角色设计
风格倾向个人 OC 角色为主
与后续的关联立绘拆分需求直接催生了 Live2D 阶段的到来

人物立绘是连接纯艺阶段与 Live2D 阶段的关键桥梁——正是因为积累了一些 OC 立绘，才产生了让角色动起来的动机，进而接触 Live2D。

书籍排版与实体输出（Adobe InDesign）

课程要求使用 Adobe InDesign 进行书籍排版，并完成实体打印输出。

内容 说明
软件Adobe InDesign（ID）
学习内容书籍排版规范、版式设计、图文混排
材质认知了解不同纸张材质（铜版纸、哑粉纸、特种纸等）及封面材质（精装硬壳、软装、覆膜工艺等）
最终产出排版完成的书稿，实际打印输出为实体书

InDesign 排版 + 实体印刷是一个完整的"数字→物理"输出流程。对纸张、封面材质的认知与后续3D材质质感表现有底层相通——都在关注材料表面的视觉与触觉特性。

After Effects 动画（MG动画 + 骨骼绑定）

使用 After Effects 进行动画创作，涵盖 MG 动画和人物骨骼绑定动画两种类型。

内容 说明
MG动画Motion Graphics 动态图形动画
人物骨骼绑定在 AE 中为2D人物做骨骼绑定，实现角色动作动画
效果角色成功动起来了
与后续的关联AE 的骨骼绑定概念与 Spine/Live2D 的绑骨逻辑一脉相承，是2D骨骼动画的最早实践

AE 骨骼绑定是 Spine 和 Live2D 之前的一次"预演"——虽然工具不同，但"拆分部件 → 绑定骨骼 → 驱动动画"的核心逻辑是相通的。

③ 2D动画工具探索

大一及紧随其后的阶段，零散接触了三款2D动画工具：Live2D（虚拟主播/立绘动态）、Spine（2D游戏骨骼动画）、VRoid Studio（3D虚拟角色拼装）。三者定位不同，但都在这一时间段进入了我的创作工具箱。以下为压缩合并的核心流程与经验总结，各工具的完整日志请点击文末相关日志链接跳转。

Live2D Cubism

制作软件：Live2D Cubism Editor
制作内容：OC 角色2D全身人体拆分 → 可动人物动态图
使用时段：2023年1月—2月（春节期间）
使用性质：兴趣驱动、业余探索

核心流程

步骤 关键操作
1. 立绘拆分将完整2D角色立绘拆为多个独立图层部件（头、眼、嘴、身体、四肢、服装等）
2. 导入 PSDLive2D Cubism Editor 导入分层PSD，自动识别图层
3. 网格生成为每个部件生成网格（Art Mesh），弯曲区域加密
4. 变形器设置创建弯曲/旋转变形器，搭建层级结构
5. 参数绑定绑定角度/眨眼/嘴巴/呼吸/头发摆动等参数
6. 物理模拟为头发、裙摆添加物理摆动
7. 导出导出 .model3.json（VTube Studio）或动态图/视频

时间线

开始接触
2023年1月

春节假期期间开始接触 Live2D Cubism

OC 角色动态制作
2023年1月—2月

为 OC 角色进行全身人体拆分与动态制作

停止使用
2023年2月后

停止使用，未再持续深入

关键注意事项

  • 拆分是重中之重：立绘拆分的精细程度直接决定最终动态效果的上限，宁可拆多不可拆少
  • 补全被遮挡区域：部件运动时会露出原本被遮挡的部分，必须提前补画
  • 命名规范：PSD 图层命名要清晰，方便在 Live2D 中管理
  • 网格密度权衡：弯曲区域加密，平坦区域可疏，控制三角面数量以保证性能
  • 参数不宜过多：入门先做好基础参数（头部转动、眨眼、呼吸），再扩展表情
  • 全身模型工作量大：建议先从半身练手

Spine

制作软件：Spine（Esoteric Software）
制作内容：2D 游戏角色骨骼绑定与动画、场景动态骨骼绑定
使用时段：2023年6月起，短期间断使用，后转3D停止
使用性质：项目驱动，围绕2D游戏开发需求

核心流程

步骤 关键操作
1. 素材拆分按关节拆分角色立绘（头、躯干、上臂、前臂、手等），场景元素按需拆出
2. 骨骼创建在 Setup Mode 下创建骨骼层级，设置父子关系
3. 绑定图片将各部件图片挂载到对应骨骼上
4. IK 约束为腿部/手臂添加 IK（反向动力学），简化动画制作
5. 网格变形（Pro版）为图片添加可变形网格，顶点权重绑定到多骨骼
6. 关键帧动画骨骼位移/旋转/缩放K帧，制作 Idle/Walk/Attack 等循环
7. 导出导出 .json + .atlas + PNG 或 .skel，接入游戏引擎运行时

时间线

开始接触
2023年6月

源于组队做游戏的需求，自学软件并为OC绑定骨骼动画

角色 + 场景绑骨
2023年6月—2024年中期

学习角色骨骼绑定，完成角色动画；尝试场景动态骨骼绑定

转向3D
2024年中期

转向3D工作流（VRoid Studio → Blender），停止使用 Spine

关键注意事项

  • 骨骼层级是核心：父子关系必须正确，否则动画会出现连锁错误
  • IK 约束大幅提效：手臂/腿部的 IK 约束能极大简化行走/攻击等动画制作
  • 场景绑骨同样重要：好的2D游戏场景动态往往靠 Spine 骨骼驱动
  • Pro 版功能差异大：网格变形是 Pro 版独占，没有它很多平滑形变效果无法实现
  • 拆分需考虑动画需求：同一角色，不同动画需求下的拆分粒度不同
  • 与 Live2D 定位不同：Spine 面向游戏动画（帧动画+骨骼），Live2D 面向虚拟主播（参数+表情）

VRoid Studio

制作软件：VRoid Studio（Steam 免费版）
后续处理：Blender（VRM Add-on 插件）
使用时段：2024年4月 — 约1个月（断续使用）
使用性质：兴趣驱动、业余探索，非正式项目

核心流程

步骤 关键操作
1. 角色创建模块化拼装：脸型、发型、身体、服装、配饰 → 滑块微调
2. 自定义素材导入自定义发型/服装/配饰（.glb），需提前做好UV和材质
3. 自动绑骨软件自动生成人形骨骼、权重分配、表情BlendShape
4. 导出 VRM填写模型信息和许可条款，导出 .vrm 格式
5. Blender 后续安装 VRM Add-on → 导入VRM → 检查骨骼/材质 → 调整 → 重新导出

时间线

下载安装
2024年4月

于 Steam 下载 VRoid Studio，开始尝试制作 OC 角色

断续使用
2024年4月—5月

断续使用约1个月，期间拼装了若干 OC 小人

停止使用
2024年5月后

停止使用，未再持续深入

关键注意事项

  • 自定义素材需提前规范：导入前确认模型UV、法线、材质球命名规范
  • VRM ≠ GLB：VRM 是 glTF 扩展格式，含骨骼映射/表情元数据，直接改后缀名无效
  • 骨骼绑定不可手动干预：VRoid 自动绑定，如需自定义骨骼需导入 Blender 后操作
  • 材质差异：VRoid 使用 MToon 着色器，Blender 中需对应调整
  • 导出前备份：VRoid 项目文件和导出的 VRM 分开保存
  • 许可条款务必填写：导出 VRM 时必须选择使用许可

④ 阶段反思 + 定位

当时的感受

  • 又累又忙又没意义——这是对这一阶段最直观的评价
  • 涉及方向过多，精力分散，难以在单一领域深入
  • 综合材料绘画的创作周期长、反馈慢，缺乏即时成就感
  • 课程任务（拍摄、纪录片、剪辑）特别杂，需要同时处理多个项目

事后回看的价值

虽然当时觉得没意义，但从完整时间线来看，这一阶段并非毫无产出：

看似无意义的经历 实际产生的后续影响
综合材料实验培养了对材质/质感的敏感度，影响后续3D材质理解
人物立绘积累直接成为 Live2D 拆分的基础素材
InDesign 排版+印刷对纸张/封面材质的认知，与3D材质质感表现底层相通
AE 骨骼绑定动画2D骨骼动画的最早实践，与 Spine/Live2D 绑骨逻辑一脉相承
AE MG动画动态图形基础，对运动节奏和关键帧的理解
剪辑/拍摄训练镜头语言与叙事节奏的基本功
高强度多任务并行锻炼了快速切换工作状态的能力
Blender 首次自学种下3D工具的种子，再次拾起时已有基础认知
ZBrush 高中体验建立了对数字雕刻工具的初步印象
3ds Max/ZBrush 7月自学3D工具入门，建立基础认知
2024年线上班学习第一次系统学习3D全流程，打通建模到材质渲染的概念链路
UV与贴图学习掌握UV拆分和贴图绘制技术，为后续3D资产制作打基础
顶点着色学习了解另一种着色方式，扩展技术视野
八猴渲染器学习实时渲染，快速预览材质效果
KeyShot渲染器掌握另一款渲染工具，丰富渲染手段

阶段定位——完整时间线中的角色

大一阶段是整个路径的起点——虽然当时方向分散、体验不佳，但立绘产出直接推动了 Live2D 的尝试，综合材料的材质感知也在3D阶段发挥了作用，2024年线上班的系统学习（包括UV、贴图、顶点着色、八猴、KeyShot渲染）则标志着正式进入3D领域。
