NPR 研究日志

Unity 与 Unreal Engine 双引擎并行，系统探索卡通风格渲染的落地方案

📅 2025 年 4 月 9 日 🗂️ 分类：NPR / Shader 🖥️ 引擎：Unity · Unreal Engine
项目信息：本项目是对非真实感渲染（NPR）技术的系统研究与实践， 并行在 Unity 与 Unreal Engine 两套引擎中验证卡通风格的着色、描边、色调分离与风格化后处理等关键环节，为后续项目积累可复用的材质管线。

一、项目背景

这个项目是对 Unity / Unreal Engine 双引擎 下的非真实感渲染做系统性研究， 目标是探索并实现一套能在两个引擎里都落地的高质量卡通风格渲染方案。 通过对比 ShaderGraph 与材质编辑器、URP 与各自渲染管线的差异，整理出可跨引擎复用的 NPR 实现思路。

整个过程中对卡通着色、描边、色调分离、风格化后处理、材质体系等关键能力做了逐一验证， 为之后的游戏类项目提前打下了风格化渲染的技术基础。

二、技术栈

  • Unity / Unreal Engine 双引擎并行实现
  • URP（Unity）与 Unreal 材质系统
  • ShaderGraph / 材质编辑器
  • C# / Blueprints 联动逻辑
  • 非真实感渲染（NPR）核心理论与实践

三、主要开发内容

3.1 卡通渲染系统

构建了一套完整的卡通渲染系统，包含以下部分：

  • 基于 ShaderGraph / 材质编辑器的卡通着色器实现
  • 多种边缘检测与描边方案
  • 色调分离与色彩层级调整
  • 高光与阴影的卡通化处理

3.2 材质体系

针对不同用途整理了一套卡通风格材质：

  • 角色材质
  • 场景材质
  • 特效材质
  • UI 材质

3.3 风格化后处理

后处理阶段也做了对应的风格化处理：

  • 卡通适配的 Bloom
  • 色彩校正
  • 描边后处理
  • 风格化滤镜

四、核心功能要点

卡通着色器

支持颜色渐变、边缘检测和高光控制，能在双引擎中稳定输出高质量的卡通风格。

描边效果

整理了物体空间描边和屏幕空间描边等多种方案，解决不同视角和距离下的描边一致性。

色调分离

把连续色彩转换成离散色调，让画面整体更贴近二维手绘的视觉特征。

风格化后处理

做了和卡通风格匹配的后处理管线，包含 Bloom、色彩校正等增强项。

材质系统

整理了角色 / 场景 / 特效 / UI 等不同对象的卡通材质体系，可跨项目复用。

性能优化

针对 NPR 的关键链路做性能优化，在视觉效果和实时帧率之间取得平衡。

五、主要技术挑战

  • 描边一致性：不同视角和距离下，描边粗细、视觉清晰度都要稳定
  • 色彩方案：为卡通风格设计稳定的色调分离与色彩调整链路
  • 性能平衡：在实时应用里维持视觉效果和帧率的平衡
  • 材质扩展性：建立可扩展的材质体系，适配多种卡通风格
  • 后处理匹配：后处理效果和整体卡通风格保持统一，不互相打架
  • 双引擎差异：把同一套 NPR 方法论在 Unity / Unreal 两套引擎里都落地
