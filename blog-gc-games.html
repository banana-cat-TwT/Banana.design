GC 游戏编辑器使用体验

学生时代用零门槛编辑器做的小屋项目合集，也是口袋崽崽的早期雏形

2023年10月 分类：引擎研究
研究软件：GC 游戏编辑器 + TypeScript + Photoshop
项目性质：大二期间为自己画的 QQ 人角色搭建一系列风格化小屋
记录日期：2023年10月（原始内容留存）
归档定位：编辑器体验留存 + 口袋崽崽早期雏形记录

一、项目介绍

在大二期间，我使用 GC 游戏编辑器开发了一系列小游戏，为自己画的 QQ 角色设计了各种风格的小屋。这些项目是角色雏形的早期版本，展示了我在游戏开发和角色设计方面的早期尝试。通过这些项目，我学习了游戏编辑器的使用、角色设计、场景构建和基本的游戏逻辑实现。

二、技术栈

使用的技术和工具：

  • GC 游戏编辑器
  • TypeScript
  • Photoshop（角色和场景设计）
  • 视频处理工具

三、做过的小屋项目

一共搭了 5 套不同风格的空间，也是口袋崽崽里「不同风格小家」这个方向的最早雏形：

Yuki 的小屋

一个温馨的日式风格空间，包含床、书桌、窗户、台灯、电视等物品，为 Yuki 角色创建了一个舒适的生活空间。

特点：详细的家居设计、温馨的色彩搭配、完整的空间布局

波西米亚风格空间

一个自由的波西米亚风格空间，展示了不同的室内设计风格，体现了波西米亚风格的特点。

特点：波西米亚装饰风格、自由的色彩搭配、随意的物品设计

熊猫的房间

为熊猫角色设计的空间，包含熊猫桌、窗户、台灯、储物柜等家具，展示了熊猫的生活空间。

特点：熊猫角色设计、日式风格房间、详细的家具和装饰品

科研用房

一个科研主题的空间，展示了不同功能空间的设计，展示了多样化的场景创作能力。

特点：科研主题、功能化布局、专业的场景设计

美式风格空间

一个充满个性的美式风格空间，包含沙发、电视、台灯、电视等元素，展示了舒适的生活空间。

特点：美式装饰风格、个性化家具、舒适的空间设计

四、开发过程

4.1 角色设计

首先设计了多个 QQ 角色，包括 Yuki、熊猫和眼镜男等，为每个角色创建了不同的服装和动作，使其具有独特的个性和风格。

4.2 场景构建

为每个角色设计了适合其个性的空间，包括日式、波西米亚、美式等不同风格，通过 GC 游戏编辑器构建了完整的场景布局。

4.3 物品设计

设计了各种家具和装饰品，包括床、书桌、台灯、电视、窗户等，为每个空间增添了细节和生活气息。

4.4 游戏逻辑实现

通过 TypeScript 编写了基本的游戏逻辑，实现了角色的移动、互动和简单的游戏功能，为每个项目添加了互动性。

4.5 资源管理

组织了音频、图像等资源，确保游戏的完整性和流畅性，为每个项目创建了独特的视觉和听觉体验。

五、项目特点

多样化的风格

展示了日式、波西米亚、美式等多种装饰风格，体现了不同文化背景下的室内设计特点。

详细的角色设计

为每个角色创建了独特的外观和个性，包括服装、动作和表情，使角色更加生动。

丰富的家具和装饰

设计了各种家具和装饰品，为每个房间增加了细节和生活气息，提高了场景的真实感。

基本的互动功能

实现了角色的移动、互动等基本功能，为游戏增添了互动性和趣味性。

六、技术难点与解决方案

难点一：场景布局和空间设计 解决方案是参考现实的室内设计案例，学习空间布局原理，通过多次调整和测试，创建了合理的空间布局。

难点二：角色动画和互动 解决方案是学习 GC 游戏编辑器的动画系统，为角色创建了基本的动作和互动逻辑，提高了游戏的趣味性。

难点三：资源管理和优化 解决方案是合理组织资源文件，优化图像和音频资源，确保游戏的流畅运行。

七、总结与展望

通过 GC 游戏编辑器开发的这些项目，我不仅学习了游戏开发的基本流程，还锻炼了角色设计、场景构建和游戏逻辑实现的能力。这些项目是角色雏形的早期版本，为后续的完善和扩展奠定了基础。

这一套内容也被视为口袋崽崽的最早雏形，之后再做桌面交互桌宠与家装风格组合时，很多角色与风格方向的选择其实在这个阶段就已经在摸索了。

后续计划：

  • 完善现有项目，添加更多互动功能和游戏玩法
  • 开发更多风格的空间和角色
  • 学习更高级的游戏开发技术，提高游戏质量
  • 将角色雏形发展成为一个完整的游戏系列
