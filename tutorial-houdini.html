0. Houdini对你这种3D美术到底有什么用？

很多人把Houdini当成「做爆炸和海浪的软件」。但对角色资产方向的你，价值在另一层：

  • 程序化资产/破损/细节：用节点一键生成破损边缘、碎石、藤蔓、鳞片排布，比手动雕刻快10倍；
  • 布料与毛发解算：Vellum（布料/绳索）、Groom（毛发）比Blender更可控，解算完可烘焙成静态mesh导回；
  • 风格化辅助：程序化纹理、随机变化、实例化，特别适合风格化角色的场景和配饰；
  • HDA工具：把流程打包成数字资产（.hda），在Unreal/Unity/Substance里直接拖用，是TA方向的核心能力。

一句话：Houdini负责接管「重复、可控、要改一百遍」的那部分工作。

1. 核心理念：程序化与非破坏性

用节点把一堆操作串成一条「菜谱」，输入一个东西，经过一串步骤，输出另一个东西。每一步都可回头改，且不会破坏原始数据。

关键比喻：乐高

  • 每个节点是一块乐高；
  • 把节点连起来就是拼装；
  • 想改造型？换一块乐高/调一下凸起的位置，整座城堡跟着变；
  • 不需要「撤销重做」，因为根本没有「破坏」这回事——你只是改了菜谱。
你在Blender里的习惯 在Houdini里对应什么
修改器栈（Mirror/Subsurf/Boolean）一层层叠 SOP节点链（本质就是无限层的修改器）
几何节点Geometry Nodes SOP/VOP（几乎同构，只是更强大）
集合/物体层级 OBJ层级
顶点组 Group（组）
顶点色/自定义属性 Attribute（属性） @Cd @P等
粒子系统 POP（粒子上下文）
物理：刚体/布料/流体 DOP（动力学）：RBD/Vellum/FLIP/Pyro
着色器节点 VOP/材质网络

2. 界面与基础操作（先认路）

面板 作用 类比
Scene View（视图） 看3D结果 Blender的3D Viewport
Network Editor（节点编辑器） 连节点、搭菜谱 几何节点编辑器
Parameter Panel（参数面板） 调当前节点参数 修改器/节点右侧的参数
Tree View/Outliner 物体层级 Outliner
Asset Browser/Shelf 预设工具架 快捷工具

必记的5个快捷键

  • Tab：在节点编辑器里搜索并添加节点（90%的操作入口）；
  • 空格+拖拽/右键：视图导航（和Blender不同，默认不是鼠标中键旋转）；
  • Enter（在节点上）：进入节点内部/聚焦；
  • U：回到上一级网络；
  • Ctrl+点击连线：断开节点连接。

新手第一坑：别在视图里直接「建模」。Houdini几乎不在视图里手捏模型，而是在节点编辑器里「生成」模型。这是思维切换的第一关。

3. 上下文全景图：Houdini的「楼层分布」

上下文 全称 干什么 你什么时候碰
OBJ Object 场景物体层级，放geo、camera、light 永远在，建场景起点
SOP Surface Operators 几何体的创建与处理（核心中的核心） 你80%的时间
DOP Dynamics Operators 物理模拟：刚体/流体/烟/布料 做破碎、海浪、烟雾时
POP Particle Operators 粒子系统（常在DOP里调用） 做粒子、群集时
VOP VEX Operators 用节点写「着色/计算」逻辑 不想写代码时的VEX替代
COP Compositing 合成（类似Nuke/后期） 出图后调色时
LOP Lighting/Solaris 灯光镜头布局（USD流程） 大项目打光时
ROP Render Operators 渲染输出节点 出图设置时

初学者策略：先死磕SOP。SOP玩明白了，VOP/VEX自然来，DOP只是「在SOP外面套一层物理规则」。不要一上来就扑去学Pyro火焰——那会劝退90%的人。

4. 数据模型：Houdini真正的内功

4.1 几何体的四个层级

  • Point（点）：空间里的一个坐标 @P；
  • Vertex（顶点）：点和面的绑定关系；
  • Primitive（图元）：面/线/体（polygon、curve、volume都算primitive）；
  • Detail（整体）：整个物体的元数据。

4.2 属性（Attribute）—— 最该理解的概念

属性 含义 例子
@P 位置（Position） 移动点就是改 @P
@N 法线（Normal） 朝向、光照
@Cd 颜色（Color，RGB） 给点染色
@scale 缩放 实例复制时每个物体大小不同
@ptnum 点的序号（0,1,2…） 用来做规律/随机
@id 唯一ID 追踪粒子

核心心法：你不是「摆放」东西，你是「通过计算属性来让东西自己长出来」。例如：想让一片草每个草高度随机 → 给每根草一个随机 @scale.y → Copy节点按属性复制 → 整片草自然错落。

4.3 组（Group）

把某些点/面圈起来，后续只对这一组操作。等价于Blender的顶点组，但更灵活（可按表达式、按属性自动生成）。

5. 新手必会的12个SOP节点

节点 作用 类比
Box/Sphere/Grid/Tube 基础几何体生成 添加网格
Transform 移动/旋转/缩放 物体变换
Scatter 在表面上撒点 分布点
Copy to Points 把模型复制到点上 Instance on Points
Attribute Create 手动建属性 新建属性
Attribute Wrangle 用VEX改属性（最强大） 自定义属性处理
Group 建组 顶点组
Boolean 布尔加减交 布尔修改器
Subdivide/PolyExtrude/Bevel 细分/挤出/倒角 对应修改器
Resample/Curve 曲线重采样、造型 曲线编辑
VOP/Attribute VOP 可视化写计算逻辑 着色器节点
Null/Output 标记输出终点 —

上手建议：先拿 Grid → Scatter（撒点）→ Copy to Points（复制小盒子）→ Transform 这条链练手，你会立刻体会到「节点串联生成画面」的爽感。

6. 实战：你的第一个程序化模型（程序化石堆/花瓣）

跟着做，10分钟出结果。目标：用节点生成「一堆大小随机的石头/花瓣」，而不是手摆。

步骤（在OBJ下新建一个Geometry，进入它的SOP网络）：

  1. 加 Grid（或Sphere当底盘）；
  2. 加 Scatter，调 Number of Points = 50，在底盘上撒50个点；
  3. 加 Attribute Randomize 给每个点生成随机 @scale（大小）和 @orient（朝向）；
  4. 另起一个分支做「单个石头」：加 Sphere → Mountain（加噪声让球凹凸成石头）→ Noise 微调；
  5. 用 Copy to Points，把「石头」接到第一个输入，「Scatter的点」接到第二个输入；
  6. 加 Null 命名为 OUT_rock，作为输出。

你会看到：50块随机大小、随机朝向的石头自动铺在底盘上。改Scatter的数量或Mountain的强度，整堆石头实时跟着变——这就是非破坏性+程序化。

7. VEX入门：别怕代码，它只是「批量改属性」

VEX（Vector Expression Language）是Houdini的高性能脚本。你不需要先学编程，只要会几个句式就能做很酷的事。所有VEX写在Attribute Wrangle节点里。

最常用句式

// 让所有点沿Y轴做正弦波动（波浪效果）
@P.y += sin(@ptnum * 0.5) * 0.1;

// 按离原点的距离给点上红→蓝色
float d = distance(@P, {0,0,0});
@Cd = set(d, 0, 1 - d);

// 给每个点随机缩放（用于Copy时大小不一）
@scale = rand(@ptnum);

// 隔一个点染成红色（按序号取模）
if (@ptnum % 2 == 0) {
    @Cd = set(1, 0, 0);
}

心智模型：VEX里你写的代码对「每一个元素」自动循环执行。你不用写for循环，Houdini帮你对每个点跑一遍。不想写代码？用VOP把同样的逻辑用节点连线画出来。

8. 模拟（DOP）入门：只在需要「物理真实」时才用

解算器 干什么 角色资产相关度
RBD（刚体） 破碎、坍塌、碰撞 高（破损道具、场景碎片）
Vellum 布料/绳索/果冻 极高（衣服、飘带、软体）
FLIP 液体 中（水花、饮料）
Pyro 烟/火/云 低（除非做特效）
POP 粒子 中（群集、沙尘）

给角色资产党的建议：Vellum和RBD是最该先学的两个。Vellum做角色衣服/披风解算后，可烘焙成动画mesh导回Blender/引擎；RBD做道具破损。Pyro火焰等你有余力再碰。

9. 灯光/摄像机/渲染

  • 灯光：在OBJ层加Light（常用环境光+主光+补光）；
  • 摄像机：OBJ层加Camera，设好焦距和构图；
  • 渲染器：
    • Karma（新版默认，基于USD，快且现代）→ 在LOP/ROP里出；
    • Mantra（老牌，稳定）→ ROP里mantra节点；
    • Redshift/Arnold/Octane（第三方，GPU快）→ 如果显卡好，Redshift出图很香。

10. 给「3D角色资产美术」的专属学习路线

阶段1：建立程序化直觉（1–2周）

  • 看《HOUDINI并不可怕》第1–2部分（基础+物体/SOP）；
  • 练：Scatter + Copy to Points + Attribute随机变化（石头/花瓣/草）；
  • 目标：能不看教程复刻一个程序化小场景。

阶段2：属性与VEX（2–3周）

  • 看Houdini 101的「属性详解/用属性复制/VOP入门」几节；
  • 练：用VEX给模型做规律变形、上色、随机；
  • 目标：理解「属性驱动一切」。

阶段3：把你已有的资产接进来（关键！）

  • 把Blender里做的角色/道具FBX/ABC导入Houdini；
  • 用RBD给道具做程序化破损边缘；用Vellum给角色做披风/衣服解算；
  • 解算完烘焙成静态/动画mesh导回Blender或引擎；
  • 目标：Houdini成为你资产流程的「增强外挂」，而不是另起炉灶。

阶段4：封装成HDA工具（TA加分项）

  • 把你的破损/毛发/程序化纹理流程打包成Houdini Digital Asset（.hda）；
  • 在Unreal/Unity里直接拖用，或在Blender外做批量处理；
  • 目标：简历上能写「可独立开发程序化资产工具」。

阶段5：按需补模拟

真要做特效时再学Pyro/FLIP/POP。

12. 新手最常踩的7个坑（FAQ）

  1. 「我能不能在视图里直接建模？」——尽量不要。Houdini是「节点生成」，不是「手捏」。强行手捏会失去程序化优势。
  2. 「为什么我连的节点没反应？」——检查：①节点是否连对输入口；②是否忘了按Ctrl+Enter让Wrangle重算；③是否在正确的上下文。
  3. 「为什么改了参数画面没变？」——Houdini有时要手动Cook。试试在节点上按Enter或加Null强制刷新。
  4. 「一上来学Pyro火焰，懵了。」——这是90%人弃坑的原因。先SOP，再谈模拟。
  5. 「属性名写错（比如@cd小写）」——Houdini区分大小写！@Cd是颜色，@cd会被当成另一个不存在的属性。
  6. 「模型导回Blender法线乱了/比例不对」——导出用FBX或Alembic(.abc)，注意单位（Houdini默认米，Blender默认米但常设毫米）。
  7. 「卡顿/内存爆炸」——高分辨率模拟前一定缓存到磁盘（File Cache/Disk Cache），别让Houdini每次都重算。
