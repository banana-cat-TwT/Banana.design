Three.js 3D 交互沙盘密码门开发日志

等距沙盘 · 昼夜循环 · 灯光系统 · UI 平滑 · 后处理 · 2026.11 迭代

Three.js WebGL 交互设计 昼夜循环 性能优化 后处理 AI 协作

为什么做这个

个人作品集网站需要一个「软门」——不是传统登录页，而是一个能让访客在输入密码之前先浏览、产生兴趣的地方。3D 沙盘恰好能承载这个意图：既是密码门，也是网站内容的可视化索引。 访客可以拖拽旋转缩放沙盘，点击建筑下方的标签直接跳转对应栏目，整个过程在一个完整的 WebGL 场景中完成，不打断视觉体验。

核心设计

  • 等距视角：固定镜头角度，建筑按等距风格堆叠，降低美术需求、快速成型
  • 自然交互：鼠标拖拽旋转、滚轮缩放，场景自己缓慢巡航，不依赖侧边栏按钮
  • 昼夜循环：90 秒一圈，太阳绕场旋转驱动光色、强度、天空色、地面曝光平滑过渡
  • 多系统灯光：建筑窗户 19:00~6:00 自动亮灯，公园路灯同步点亮（含暖光点光源），与 bloom 后处理叠加
  • UI 投影定位：3D 世界坐标实时投影到屏幕，带避让算法（躲密码卡、标签互斥、边界钳制）

完整迭代时间线

Phase 0 · 搭架子
基础渲染管线 + 等距相机
WebGLRenderer 配置（antialias、alpha、PCFSoftShadowMap、ACESFilmicToneMapping），HemisphereLight + DirectionalLight 基础光照，相机固定等距角度，实现拖拽旋转缩放。
Phase 1 · 搭场景
5 栋建筑 + 沙盘底 + 装饰
Portfolio / Blog / About 三栋主建筑 + 小桥 + 内河 + 小菜园，石头、花茎、灌木等装饰物件（全部关闭阴影以保证性能）。
Phase 2 · 删冗余 + 加昼夜
去掉 5 个侧边按钮 → 自动昼夜循环
删除自由视角/平移/自动巡航/复位/全屏五个按钮——鼠标已能自由操控，场景本身也会缓慢巡航，按钮多余。改为 90 秒一圈的太阳旋转驱动光色/强度/天空色/曝光。
Phase 3 · 无限地形
160×160 大地平面 + 42 棵随机小树
沙盘下方放大地平面，最远缩放时边缘不入视口。外圈（半径 16.5~74.5）固定种子随机撒 42 棵小树，避开沙盘和 5 个分区，营造「看起来无限的地形」。
Phase 4 · 夜间亮灯
窗户灯 + 路灯 + 点光源 + bloom
夜晚全黑看不到 → 新增 M.windowLight 发光材质 + 建筑窗户几何体，19:00~6:00 自动亮灯。公园 6 盏路灯同步点亮，其中 3 盏挂暖光点光源照亮地面。后处理异步加载 UnrealBloomPass 实现朦胧光晕，失败自动降级。
Phase 5 · 加人
行人绕圈 + 玩耍的人原地活动
中央环形步道（半径 5.2，避开建筑地台）放 8 个行人慢慢绕圈走，朝向随切线。中央空地放 9 个玩耍的人各自小范围来回转圈，速度、半径、方向都随机。
Phase 6 · 修卡顿
阴影贴图 1536 → 1024 + dt 钳制放宽
点击 UI 框时视角转换卡顿 → 三层优化：阴影贴图降分辨率；dt 钳制从 0.06 放宽到 0.25（避免掉帧时补间步长一起被砍）；所有装饰物件关闭阴影。
Phase 7 · 修抖动（两轮迭代）
UI 标签旋转时高频抖动
根因：避让算法（pushOffCard / 标签互斥 / clampX）的目标位置本身在高频跳变，平滑层追着抖动目标跑。
第一轮（失败）：固定系数 lerp s.x += (tx - s.x) * 0.18 → 仍然抖。
第二轮（当前方案）：死区 1.5px + 混合限速滑行 Math.min(2.2, d * 0.22)。近距离指数衰减、远距离限速滑行，杜绝跳变。

技术要点速查

  • 昼夜循环分层驱动：dayPhase（0~1）→ 太阳位置 → 光色/强度/天空色/地面色/曝光；hourOfDay = (dayPhase * 24 + 6) % 24 → 窗户灯/路灯 emissiveIntensity + PointLight 开关。新增灯具只需接 hourOfDay 判断
  • 性能三原则：阴影贴图 1024、非必要物件不投影、dt 钳制 0.25
  • 异步后处理降级：动态 import UnrealBloomPass，try 包 RenderPass，失败自动降级普通渲染
  • UI 平滑通用方案：悬浮标签/提示框防抖的标准解法——识别避让算法源头抖动，用死区 + 限速滑行替代固定 lerp

AI 协作记录

开发过程中有另一个 AI（Workbuddy）在并行改同一个文件，期间有覆盖风险。以下是协作中形成的约束：
  • 关键代码片段带唯一签名：昼夜循环参数、灯光联动逻辑、UI 平滑算法等核心段落加注释标识，被覆盖时能快速 diff 找回
  • 功能块解耦：每块功能独立命名（streetlight / pedestrians / dayPhase / smoothPills），避免 AI 合并时误删
  • 性能参数集中配置：阴影分辨率、dt 钳制、bloom 参数等放在一起，方便不同 AI 调整时不互相踩

可复用性

这套 Three.js 沙盘搭建脚手架可以直接套用到其他项目：
  • 基础几何函数库（box / cyl / sph / cap / prism / rand）
  • 材质字典 M + 统一 shadowMapSize 配置
  • 昼夜循环参数体系（dayPhase / hourOfDay 分层驱动）
  • UI 悬浮标签防抖通用方案（死区 + 限速滑行）
  • 异步后处理降级模板
