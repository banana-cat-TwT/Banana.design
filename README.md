## 项目简介

本项目是我（巴拿拿猫）的个人作品集网站，集中展示：

- 3D 角色 / 场景美术作品（ZBrush / Blender / Substance Painter / Marmoset Toolbag）
- Unity / Unreal Engine 游戏项目与交互原型
- Shader 开发（HLSL / GLSL / Shader Graph / Material）
- AI 3D 生成 / 生图 / 工作流自动化研究日志
- 个人博客（包含 Meshy AI、Tripo3D、混元3D、SPUE Bridge、Stardew Valley MOD 等多篇研究笔记）
- 简历页与自我介绍页

## 技术栈

前端纯静态实现：HTML + CSS + 原生 JavaScript，无打包、无依赖。
