0. 先说人话：为什么美术要学这个

你平时在 Blender 里干的这些活，其实都能用一行行代码代替：

  • 一次性给 200 个物体统一改名 / 加后缀
  • 批量把一个文件夹里 50 个 .fbx 导入、居中、再导出成 .obj
  • 给所有选中的物体套同一个材质
  • 一键把高模复制一份、加个 Decimate（减面）修改器、烘焙用的低模就出来了
  • 半夜自动渲染 100 个角色的转盘图

核心逻辑很简单：你在 Blender 界面点的每一个按钮，背后都对应一句 Python 代码。学会自动化 = 学会"不用手点、让代码替你点"。

你不需要变成程序员，只需要会照葫芦画瓢改脚本，就已经能省掉大量重复劳动。

1. 环境准备：把脚本工作区调出来

1.1 打开 Scripting 工作区

Blender 顶部有一排工作区标签（Layout / Modeling / Sculpting…），拉到最右边点 Scripting。

区域 名字 作用
左下 Python Console（交互控制台） 输一行执行一行，试代码用
中间 Text Editor（文本编辑器） 写完整脚本，点 ▶ 运行
左上 Info / 3D视图 看操作对应的代码

1.2 打开"信息窗口"看代码提示（超重要的偷懒技巧）

Blender 会把你每一步鼠标操作，翻译成代码显示出来。

方法：把某个窗口的类型切换成 Info（信息）（点窗口左上角那个图标下拉菜单选 Info）。

bpy.ops.transform.translate(value=(0, 0, 1.5))
bpy.ops.object.delete()

这招是新手最快的学习方式：不知道某个功能的代码怎么写？先用鼠标点一次，去 Info 窗口抄答案。

1.3 打开系统控制台（看报错必备）

  • Window（窗口）菜单 → Toggle System Console（切换系统控制台）
  • 会弹出一个黑色的命令行窗口，你的 print() 输出和红色报错都在这里显示。
  • 写脚本时建议一直开着，出错了才知道错在哪。

1.4 建议勾选的设置

Edit → Preferences → Interface → 勾选 Python Tooltips 和 Developer Extras

勾选后，把鼠标悬停在任意按钮上，提示框里会直接告诉你这个按钮对应的 Python 命令。

2. Python极速入门（只学够用的）

2.1 变量：给东西起个名字存起来

name = "角色A"      # 文字（字符串），要用引号
count = 5           # 整数
scale = 1.5         # 小数（浮点数）
is_low_poly = True  # 布尔值：True / False

变量就是一个"盒子"，把值装进去，后面用名字就能取出来。

2.2 数据类型速记

类型 例子 说明
字符串 str "Cube" 文字，必须加引号
整数 int 10 没有小数点的数
浮点数 float 1.75 带小数点
布尔 bool True / False 是/否，开/关
列表 list [1, 2, 3] 一串东西，有顺序
元组 tuple (0, 0, 1) 和列表像，但不可改（常用于坐标/颜色）

2.3 列表（超级常用）

positions = [0, 5, 10]
positions[0]        # 取第1个（从0开始数！）→ 0
positions[-1]       # 取最后一个 → 10
positions.append(15)  # 往后加一个 → [0, 5, 10, 15]
len(positions)      # 数一共几个 → 4

重点：编程里数数从 0 开始。第一个是 [0]，第二个是 [1]。

2.4 判断：如果……就……

if count > 3:
    print("数量够多")
else:
    print("数量太少")

注意：if 那行末尾有冒号 :，下面的语句要缩进（按 Tab 或 4 个空格）。缩进在 Python 里不是好看，是语法，错了会报错。

2.5 循环：把同一件事重复做（自动化的核心！）

for i in [1, 2, 3]:
    print(i)
# 输出 1、2、3

for obj in bpy.context.selected_objects:
    print(obj.name)
# 依次打印每个被选中物体的名字

for ... in ...: 的意思是"对里面的每一个东西，都做一遍下面的操作"。批量处理 = 循环。记住这句就够了。

2.6 函数：把一段代码打包成一个"技能"

def say_hello(name):
    print("你好，" + name)

say_hello("角色A")   # 调用它 → 你好，角色A

3. bpy是什么：Blender的"遥控器"

import bpy

bpy = Blender Python，是 Blender 官方提供的 Python 接口。你可以把 bpy 理解成 Blender 的遥控器：想让 Blender 干啥，就通过 bpy 下命令。

4. 三大核心模块：data / context / ops

这是整个 Blender Python 最重要的三个概念，理解它们就理解了 80%。

4.1 bpy.data —— 文件里的所有数据（"仓库"）

bpy.data.objects        # 所有物体
bpy.data.objects["Cube"]  # 名叫 Cube 的物体
bpy.data.materials      # 所有材质
bpy.data.meshes         # 所有网格数据
bpy.data.collections    # 所有集合
bpy.data.scenes         # 所有场景

# 数一共有多少个物体
print(len(bpy.data.objects))

# 遍历所有物体名字
for obj in bpy.data.objects:
    print(obj.name)

特点：通过名字精准访问，不管它选没选中、在不在当前视图，只要文件里有就能拿到。最稳定、最推荐用它来批量处理。

4.2 bpy.context —— 当前状态（"现在选中/激活的是谁"）

bpy.context.object              # 当前激活物体（描边偏亮的那个）
bpy.context.active_object       # 同上
bpy.context.selected_objects    # 所有被选中的物体（列表）
bpy.context.scene               # 当前场景
bpy.context.mode                # 当前模式（OBJECT / EDIT_MESH...）
bpy.context.view_layer.objects.active  # 设置/获取激活物体

特点：跟随你的鼠标选择变化。"处理我选中的这些"就用它。

小坑：激活物体（active）和选中物体（selected）不是一回事。你可以同时选中 5 个（selected），但激活的（active）只有 1 个（最后点的那个，描边最亮）。

4.3 bpy.ops —— 操作命令（"点按钮"）

bpy.ops.mesh.primitive_cube_add()      # 添加一个立方体
bpy.ops.object.delete()                # 删除选中的
bpy.ops.transform.translate(value=(0, 0, 2))  # 沿Z轴移动2米
bpy.ops.object.shade_smooth()          # 平滑着色
bpy.ops.object.modifier_add(type='SUBSURF')   # 加细分修改器

特点：简单直观（跟点按钮一样），但有个大坑——ops 依赖"上下文（context）"，也就是它默认作用于"当前选中/当前鼠标所在的窗口"。在脚本里批量跑时容易出现 context is incorrect 报错。

新手准则：

  • 能用 bpy.data 直接改属性的，优先用 bpy.data（稳）。
  • 只有某些复杂操作（比如加修改器、进出编辑模式）才用 bpy.ops。
# 方式A：ops（模拟点按钮，依赖选中状态）
bpy.ops.transform.translate(value=(0, 0, 2))

# 方式B：直接改数据（更稳，推荐）
bpy.data.objects["Cube"].location.z += 2

5. 操作对象：选中、移动、改名、删除

5.1 拿到一个物体

obj = bpy.data.objects["Cube"]   # 按名字拿
obj = bpy.context.active_object   # 拿当前激活的

5.2 读写它的常见属性

obj.name = "角色_头部"                # 改名
obj.location = (1.0, 2.0, 0.0)      # 位置 (x, y, z)
obj.location.z = 5                   # 只改 Z
obj.rotation_euler = (0, 0, 1.5708)  # 旋转（弧度！90°≈1.5708）
obj.scale = (2, 2, 2)                # 缩放
obj.hide_set(True)                   # 在视图里隐藏
obj.hide_render = True               # 渲染时隐藏

旋转是弧度不是角度。想用角度，用 math 转换：

import math
obj.rotation_euler.z = math.radians(90)  # 90度

5.3 选中 / 取消选中

# 先全部取消选中
bpy.ops.object.select_all(action='DESELECT')

# 选中某个物体
obj = bpy.data.objects["Cube"]
obj.select_set(True)

# 把它设为激活物体（很多 ops 需要有激活物体）
bpy.context.view_layer.objects.active = obj

5.4 创建物体

bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
bpy.ops.mesh.primitive_uv_sphere_add(radius=1, location=(3, 0, 0))
bpy.ops.object.camera_add(location=(0, -10, 5))
bpy.ops.object.light_add(type='SUN', location=(0, 0, 10))

5.5 删除物体

# 方式A：删选中的
bpy.ops.object.delete()

# 方式B：按名字精准删（推荐批量时用）
obj = bpy.data.objects["Cube"]
bpy.data.objects.remove(obj, do_unlink=True)

6. 循环批量处理（自动化的灵魂）

6.1 遍历所有选中的物体

import bpy

for obj in bpy.context.selected_objects:
    print(obj.name)          # 打印名字
    obj.location.z += 1      # 每个都抬高1米

6.2 只处理网格类型的物体（过滤）

for obj in bpy.data.objects:
    if obj.type == 'MESH':      # 只要网格
        obj.select_set(True)

常见 type：'MESH'（网格）、'CAMERA'、'LIGHT'、'ARMATURE'（骨架）、'EMPTY'（空物体）。

6.3 批量改名（带序号）

import bpy

selected = bpy.context.selected_objects

for i, obj in enumerate(selected):   # enumerate 同时给出序号 i
    obj.name = f"Character_{i:03d}"  # Character_000, Character_001...

f"..._{i:03d}" 里的 03d 表示补零成3位数。f"..." 是 f-string，能把变量嵌进文字里，超好用。

7. 实战案例合集（可直接抄）

用法：复制到 Text Editor，改改路径/参数，点 ▶ Run Script（或按 Alt+P）。

案例1：给所有选中物体统一加后缀

import bpy

suffix = "_LP"   # 想加的后缀，比如低模标记

for obj in bpy.context.selected_objects:
    obj.name = obj.name + suffix
    # 同时把它的网格数据也改名（可选，习惯好）
    if obj.data:
        obj.data.name = obj.name

print("改名完成！")

案例2：一键清空场景（重开画布）

import bpy

# 删除所有物体
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.delete()

# 清理没人用的数据块（材质、网格残留）
for block in bpy.data.meshes:
    if block.users == 0:
        bpy.data.meshes.remove(block)

print("场景已清空")

案例3：批量导入一个文件夹里所有 FBX

import bpy
import os

# 改成你的文件夹路径（Windows 用 / 或 \\，别用单个 \）
folder = "F:/models/fbx_in"

for filename in os.listdir(folder):
    if filename.lower().endswith(".fbx"):
        filepath = os.path.join(folder, filename)
        bpy.ops.import_scene.fbx(filepath=filepath)
        print("已导入:", filename)

print("全部导入完成")

案例4：批量把选中物体各自导出成 OBJ

import bpy
import os

out_folder = "F:/models/obj_out"
os.makedirs(out_folder, exist_ok=True)  # 文件夹不存在就创建

for obj in bpy.context.selected_objects:
    # 只选中当前这一个
    bpy.ops.object.select_all(action='DESELECT')
    obj.select_set(True)
    bpy.context.view_layer.objects.active = obj

    filepath = os.path.join(out_folder, obj.name + ".obj")
    # Blender 4.x 用新的导出算子；旧版是 export_scene.obj
    bpy.ops.wm.obj_export(filepath=filepath, export_selected_objects=True)
    print("已导出:", obj.name)

print("批量导出完成")

版本差异提示：Blender 4.x 导出 OBJ 用 bpy.ops.wm.obj_export(...)；3.x 用 bpy.ops.export_scene.obj(...)。不确定就去 Info 窗口手动导一次抄代码。

案例5：给所有选中物体套同一个材质

import bpy

# 新建一个材质
mat = bpy.data.materials.new(name="通用材质")
mat.use_nodes = True
# 设个基础色（RGBA，0~1）
bsdf = mat.node_tree.nodes.get("Principled BSDF")
if bsdf:
    bsdf.inputs["Base Color"].default_value = (0.8, 0.2, 0.2, 1.0)

for obj in bpy.context.selected_objects:
    if obj.type == 'MESH':
        obj.data.materials.clear()      # 清掉原材质
        obj.data.materials.append(mat)  # 套上新的

print("材质已批量应用")

案例6：批量加"平滑着色 + 细分修改器"

import bpy

for obj in bpy.context.selected_objects:
    if obj.type != 'MESH':
        continue
    bpy.context.view_layer.objects.active = obj

    # 平滑着色
    bpy.ops.object.shade_smooth()

    # 加细分修改器
    mod = obj.modifiers.new(name="Subdiv", type='SUBSURF')
    mod.levels = 1          # 视图层级
    mod.render_levels = 2   # 渲染层级

print("处理完成")

案例7：批量减面（做低模常用）

import bpy

ratio = 0.3   # 保留 30% 的面

for obj in bpy.context.selected_objects:
    if obj.type != 'MESH':
        continue
    mod = obj.modifiers.new(name="Decimate", type='DECIMATE')
    mod.ratio = ratio
    # 如果想直接烘死（应用修改器）：
    bpy.context.view_layer.objects.active = obj
    bpy.ops.object.modifier_apply(modifier=mod.name)

print("减面完成")

8. 进阶：做一个自己的按钮/面板/插件

8.1 最小可用面板（在右侧 N 面板里加一个标签）

import bpy

# 1) 定义一个操作（按钮点了干啥）
class OBJECT_OT_add_suffix(bpy.types.Operator):
    bl_idname = "object.add_suffix_lp"   # 唯一ID，格式 类别.名字
    bl_label = "给选中物体加_LP后缀"       # 按钮上的文字

    def execute(self, context):
        for obj in context.selected_objects:
            obj.name = obj.name + "_LP"
        self.report({'INFO'}, "改名完成")   # 顶部提示
        return {'FINISHED'}

# 2) 定义一个面板（按钮放哪）
class VIEW3D_PT_my_tools(bpy.types.Panel):
    bl_label = "我的工具"
    bl_idname = "VIEW3D_PT_my_tools"
    bl_space_type = 'VIEW_3D'
    bl_region_type = 'UI'
    bl_category = "我的工具"   # N面板里的标签名

    def draw(self, context):
        layout = self.layout
        layout.operator("object.add_suffix_lp")  # 放上那个按钮

# 3) 注册
classes = [OBJECT_OT_add_suffix, VIEW3D_PT_my_tools]

def register():
    for cls in classes:
        bpy.utils.register_class(cls)

def unregister():
    for cls in classes:
        bpy.utils.unregister_class(cls)

if __name__ == "__main__":
    register()

结构记忆：

  • Operator（操作符） = 按钮的功能，核心在 execute() 里写你的逻辑。
  • Panel（面板） = 界面容器，draw() 里决定放哪些按钮。
  • register/unregister = 告诉 Blender "把我的东西挂上/卸下"。

9. 角色资产工作流专用脚本

9.1 一键生成"烘焙用低模"（高模复制 + 减面 + 改名）

import bpy

DECIMATE_RATIO = 0.25   # 低模保留比例

for high in list(bpy.context.selected_objects):
    if high.type != 'MESH':
        continue

    # 复制一份作为低模
    low = high.copy()
    low.data = high.data.copy()   # 网格也复制，避免共享
    low.name = high.name + "_low"
    bpy.context.collection.objects.link(low)

    # 给低模加减面
    mod = low.modifiers.new(name="Decimate", type='DECIMATE')
    mod.ratio = DECIMATE_RATIO

    # 高模也统一改名规范
    if not high.name.endswith("_high"):
        high.name = high.name + "_high"

print("高低模已生成，记得检查UV/法线")

9.2 检查场景里面数过高的物体（优化排查）

import bpy

LIMIT = 50000   # 面数上限

print("===== 面数检查 =====")
for obj in bpy.data.objects:
    if obj.type == 'MESH':
        # 需要用 evaluated 拿到应用修改器后的真实面数（简化版直接读原始网格）
        poly_count = len(obj.data.polygons)
        flag = "  ⚠超标" if poly_count > LIMIT else ""
        print(f"{obj.name}: {poly_count} 面{flag}")

9.3 批量应用所有修改器（交付前烘死）

import bpy

for obj in bpy.context.selected_objects:
    if obj.type != 'MESH':
        continue
    bpy.context.view_layer.objects.active = obj
    for mod in list(obj.modifiers):
        try:
            bpy.ops.object.modifier_apply(modifier=mod.name)
        except RuntimeError as e:
            print(f"{obj.name} 的 {mod.name} 应用失败: {e}")

print("修改器已应用")

9.4 批量设置 Transform（清零位置 + 应用缩放）

import bpy

for obj in bpy.context.selected_objects:
    bpy.ops.object.select_all(action='DESELECT')
    obj.select_set(True)
    bpy.context.view_layer.objects.active = obj
    # 应用旋转和缩放（保留位置）
    bpy.ops.object.transform_apply(location=False, rotation=True, scale=True)

print("旋转/缩放已应用，scale 现在都是 1")

9.5 自动渲染转盘图（角色展示）

import bpy
import math
import os

obj = bpy.context.active_object
frames = 8                          # 转8个角度
out = "F:/renders/turntable"
os.makedirs(out, exist_ok=True)

for i in range(frames):
    obj.rotation_euler.z = math.radians(360 / frames * i)
    bpy.context.scene.render.filepath = os.path.join(out, f"turn_{i:02d}.png")
    bpy.ops.render.render(write_still=True)
    print(f"已渲染第 {i+1}/{frames} 张")

print("转盘渲染完成")

10.3 常见报错对照表

报错信息 人话翻译 解决
KeyError: 'Cube' 找不到名叫 Cube 的东西 名字打错了/物体不存在，检查拼写
AttributeError: ... has no attribute ... 这个东西没有你写的那个属性 属性名错了，用 dir() 查正确名字
RuntimeError: Operator ... context is incorrect ops 找不到合适的上下文 鼠标/选中状态不对，改用 bpy.data 直接改，或先设好 active/selected
IndentationError 缩进错了 检查每行前面的空格/Tab 是否对齐
SyntaxError 语法写错了 多半是漏了 :、引号、括号没配对
NoneType has no attribute 你想操作的东西是"空的"(None) 比如没选中任何物体，active_object 是 None，先判断 if obj:

10.4 bpy.ops 报 context 错误的经典解法

bpy.ops.object.select_all(action='DESELECT')
obj.select_set(True)
bpy.context.view_layer.objects.active = obj   # 关键：设激活
bpy.ops.object.shade_smooth()                 # 现在能跑了

结语

自动化的本质就一句话：把手工重复的操作，写成循环让代码替你跑。

建议你今天就从案例1（批量改名） 或 9.4（清零Transform） 开始，跑通一个，你就入门了。后面遇到任何"这活好烦、要重复好多次"的时刻，回来翻这份文档找对应模板改一改就行。
