3D自动化基础工具开发日志

基于 Python 和 Blender Python API 的3D资产自动化工具开发记录，用于提升日常工作效率

📖 项目背景

在日常3D工作中，经常需要对大量模型进行重复性操作，如批量检查模型规范、自动重命名资产、批量导出等。这些操作手动执行既耗时又容易出错，因此决定开发一套基础的自动化工具。

项目目标是创建一个轻量级的工具框架，能够快速集成到现有的工作流中，减少重复性劳动，让创作者专注于设计本身。

🛠️ 目前进展

版本：v1.0（初期原型）

工具已具备基本可用性，但仍有不少功能需要完善。

  • 已完成基础框架搭建，可以正常运行
  • 部分功能模块已实现基本逻辑
  • 用户界面和交互体验待优化
  • 部分边界情况处理不完善

📦 工具功能

当前工具主要包含以下基础功能模块：

  • 模型信息读取与检查
  • 资产批量重命名
  • 基础导出功能封装
说明：工具还在持续迭代中，功能会根据实际工作需求逐步扩展。
