开发背景

日常的3D美术工作中，经常需要对大量资产进行重复性的操作，例如批量检查模型规范、自动重命名、批量导出、生成脚本等。这些操作手动执行既耗时又容易出错，因此决定开发一套3D自动化基础工具。

项目目标是创建一个可视化的工具平台，能够快速集成进现有的工作流中，减少重复性劳动，让创作者专注于设计本身。

工具定位

工具主要面向3D资产流水线的自动化处理，覆盖两个DCC平台，并支持一键执行：

  • Blender Python API：用于Blender端的资产自动化脚本生成与一键执行；
  • 3ds Max MaxScript：用于3ds Max端的资产自动化脚本生成与一键执行；

整体采用可视化界面，支持离线桌面运行，方便非程序背景的美术同事直接使用。工具本身是「脚本生成+执行器」，不直接修改模型文件，保障资产安全。

当前进展

版本：v2.0（离线桌面版），经历了从网页原型到桌面工具的一次完整迭代。

已完成的核心功能模块如下：

  • 1. 可视化界面框架：任务配置、目标选择、脚本预览等核心页面已完成，支持9类自动化任务（重命名/导入导出/材质/光滑组/法线/归零/单位/格式/转可编辑多边形）；
  • 2. 双平台脚本生成：支持生成 Blender Python 和 3ds Max MaxScript 两种格式的自动化脚本，可预览后复制使用；
  • 3. 离线桌面化（v2.0 重大更新）：双击即用、完全离线，无需联网；
  • 4. Blender 一键执行：工具可自动探测本机 Blender 路径，支持「指定文件」和「当前场景」两种执行模式，省去手动复制粘贴脚本的环节；
  • 5. 3ds Max 一键执行：同样支持自动探测本机 3ds Max 路径，提供「无界面批处理」和「界面执行」两种模式，脚本前后自动加载/保存文件，保障安全；
  • 6. 执行日志与反馈：一键执行面板底部有实时日志输出，成功/失败会有 toast 提示，方便排查问题。

当前局限与待完善点

目前工具已经覆盖了核心的脚本生成和一键执行功能，但仍有不少可以继续完善的地方：

  • 1. 首次打开 SmartScreen 警告：由于没有代码签名证书，Windows 首次打开会提示安全警告，需要手动点「仍要运行」；
  • 2. 3ds Max 破解版兼容性：破解版在「无界面批处理」模式下可能弹激活窗，遇到时需切换到「界面执行」模式；
  • 3. 执行前自动备份：指定文件模式下可增加自动备份功能，防止误改原始文件；
  • 4. 完全无人值守模式：指定输入/输出目录，一键批量处理多个文件；
  • 5. 更多 DCC 支持：目前仅支持 Blender 和 3ds Max，后续可考虑扩展 Maya等平台。

后续计划

后续开发计划大概分为以下几个方向：

  • 1. 增加执行前自动备份：指定文件模式下自动复制一份备份文件再执行，防误改；
  • 2. 完全无人值守模式：支持指定输入/输出目录，一键批量处理多个文件；
  • 3. 丰富自动化任务类型：根据实际工作需求，继续增加更多的自动化功能模块；
  • 4. 界面与体验优化：打磨交互细节，增加状态反馈和引导提示。

总结

3D自动化基础工具已经从初期的网页原型发展为功能完整的离线桌面应用，覆盖了脚本生成、一键执行、双平台支持等核心能力。从v1.0到v2.0的迭代过程中，解决了白屏、离线化、路径探测等多个实际问题，工具的可用性和稳定性得到了显著提升。

后续会继续根据实际工作需求，补充更多自动化任务类型，优化用户体验，让工具逐步成为日常资产流水线中的得力助手。
