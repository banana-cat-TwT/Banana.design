一、项目概述

2024年4月起出于兴趣尝试 VRoid Studio，主要用来制作 OC（Original Character）小人。非持续性项目，属于业余探索性质，偶尔打开软件拼装角色。利用软件内置模板与自定义素材组合角色形象，完成骨骼绑定后导出为 VRM 格式，再导入 Blender 进行后续调整。

二、时间线

时间事件
2024年4月于 Steam 下载 VRoid Studio，开始尝试制作 OC 角色
2024年4月—5月断续使用约1个月，期间拼装了若干 OC 小人
2024年5月后停止使用，未再持续深入

使用性质：兴趣驱动、业余探索，非正式项目。主要用于 OC 角色外观拼装，未涉及复杂的自定义素材导入或直播驱动流程。

三、制作流程

3.1 软件安装与初始设置

步骤说明
下载安装Steam 搜索「VRoid Studio」，免费下载安装
语言设置启动后可在设置中切换为中文界面
账号注册如需使用 VRoid Hub 分享社区，需注册账号（导出本地文件不需要）

3.2 角色创建——预制模板拼装

VRoid Studio 采用模块化拼装思路，角色由以下独立部件组合而成：

模块可调内容说明
脸型脸部轮廓、五官比例、眼睛细节捏脸系统，支持滑块微调
发型前发、后发、侧发、呆毛等内置大量发型模板，可调颜色与发梢渐变
身体身高、体型、四肢比例整体骨架比例调整
服装上衣、下装、鞋子、外套内置服装库，支持自定义导入
配饰眼镜、耳饰、帽子等丰富的小物件装饰

核心思路：先选模板 → 滑块微调 → 换色/换材质 → 拼装完成

3.3 自定义模型导入

在预制模板基础上，可以将自己制作的模型素材导入 VRoid Studio：

导入类型支持格式导入路径
自定义发型.vroidhair / .glb发型编辑器 → 导入
自定义服装.vroidwear / .glb服装编辑器 → 导入
自定义配饰.glb配饰编辑器 → 导入

注意：导入的自定义模型需提前做好UV展开和材质分配，否则在 VRoid 中无法正确显示贴图。

3.4 骨骼绑定（软件内自动完成）

VRoid Studio 内置自动骨骼绑定系统，创建角色时自动执行以下流程：

  1. 人形骨骼生成：根据角色身高体型自动适配 Humanoid 骨骼
  2. 权重自动分配：皮肤蒙皮权重自动计算
  3. 表情BlendShape生成：内置标准表情组（喜、怒、哀、惊等）
  4. 视线/手指骨骼：眼球视线控制器 + 手指独立骨骼

整个骨骼绑定过程无需手动操作，软件自动完成。这是 VRoid Studio 的核心优势之一——零门槛完成绑定。

3.5 导出 VRM 格式

角色制作完成后导出流程：

  1. 点击主界面「导出」按钮
  2. 选择导出类型：VRM 格式（.vrm）
  3. 填写模型信息（模型名、作者名、使用许可条款）
  4. 勾选「允许二次加工」等许可选项
  5. 选择保存路径，确认导出

关于格式：VRM 是基于 glTF 2.0 的扩展格式，专为3D虚拟角色设计，包含骨骼、表情、材质等元数据。与 GLB 同属 glTF 生态，但 VRM 额外携带了人形骨骼映射和表情数据。

3.6 导入 Blender 后续调整

前置准备：安装 VRM 插件

  1. 打开 Blender → 编辑 → 设置 → 插件 → 安装
  2. 下载 VRM Add-on for Blender
  3. 安装并启用插件

导入与调整流程

步骤操作说明
导入VRM文件 → 导入 → VRM插件会自动解析骨骼与材质
检查骨骼切换至姿态模式确认 Humanoid 骨骼映射正确
调整材质查看 MToon 着色器VRM 使用 MToon 渲染，Blender 中需对应调整
修改模型进入编辑模式对拓扑/布线进行微调
重新导出文件 → 导出 → VRM调整后可重新导出为 VRM

五、注意事项与经验总结

要点说明
自定义素材需提前规范导入前确认模型UV、法线、材质球命名规范，避免 VRoid 内显示异常
VRM ≠ GLBVRM 是 glTF 扩展格式，含骨骼映射/表情元数据，直接改后缀名无效
骨骼绑定不可手动干预VRoid 自动绑定，如需自定义骨骼需导入 Blender 后操作
材质差异VRoid 使用 MToon 着色器，Blender 默认 EEVEE/Cycles 渲染效果不同，需手动适配
导出前备份VRoid 项目文件和导出的 VRM 分开保存，方便后续迭代修改
许可条款务必填写导出 VRM 时必须选择使用许可，否则部分平台无法使用

六、后续可拓展方向

  • 利用 Blender 重新拓扑优化模型面数
  • 在 Blender 中烘焙 MToon → PBR 材质转换
  • 制作自定义 BlendShape 表情追加到 VRM
  • 接入 Unity（UniVRM）用于实时驱动/直播
  • 如有需要可重新拾起，作为毕设中风格化角色制作的参考对照
