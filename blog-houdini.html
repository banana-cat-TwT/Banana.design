Houdini 程序化 SOP VEX Vellum

学习背景

此前主要x进行3D资产制作，随着对程序化工作流的深入理解，继续学习Houdini。Houdini的价值不在于做爆炸和海浪，而在于：

  • 程序化资产/破损/细节：用节点一键生成破损边缘、碎石、藤蔓、鳞片排布，比手动雕刻快10倍；
  • 布料与毛发解算：Vellum（布料/绳索）、Groom（毛发）比Blender更可控，解算完可烘焙成静态mesh导回Blender/引擎；
  • 风格化辅助：程序化纹理、随机变化、实例化，特别适合风格化角色的场景和配饰；
  • HDA工具：把流程打包成数字资产（.hda），在Unreal/Unity/Substance里直接拖用，是TA方向的核心能力。

一句话总结：Houdini负责接管「重复、可控、要改一百遍」的那部分工作。

核心理念：程序化与非破坏性

Houdini的本质就是用节点把一堆操作串成一条「菜谱」，输入一个东西，经过一串步骤，输出另一个东西。每一步都可回头改，且不会破坏原始数据。

关键比喻：乐高

  • 每个节点是一块乐高；
  • 把节点连起来就是拼装；
  • 想改造型？换一块乐高/调一下凸起的位置，整座城堡跟着变；
  • 不需要「撤销重做」，因为根本没有「破坏」这回事——你只是改了菜谱。

如果你玩过Blender的几何节点，那Houdini对你来说不是从零开始，只是把那套逻辑放大了100倍。

上下文全景图：Houdini的「楼层分布」

初学者策略：先死磕SOP。SOP玩明白了，VOP/VEX自然来，DOP只是「在SOP外面套一层物理规则」。不要一上来就扑去学Pyro火焰——那会劝退90%的人。

数据模型：Houdini真正的「内功」

这是和Blender最大不同的地方。一切都是数据。

几何体的四个层级

  • Point（点）：空间里的一个坐标 @P；
  • Vertex（顶点）：点和面的绑定关系；
  • Primitive（图元）：面/线/体（polygon、curve、volume都算primitive）；
  • Detail（整体）：整个物体的元数据。

属性（Attribute）—— 最该理解的概念

属性 含义 例子
@P 位置（Position） 移动点就是改 @P
@N 法线（Normal） 朝向、光照
@Cd 颜色（Color，RGB） 给点染色
@scale 缩放 实例复制时每个物体大小不同
@ptnum 点的序号（0,1,2…） 用来做规律/随机

核心心法：你不是「摆放」东西，你是「通过计算属性来让东西自己长出来」。例如：想让一片草每个草高度随机 → 给每根草一个随机 @scale.y → Copy节点按属性复制 → 整片草自然错落。

上手建议：先拿 Grid → Scatter（撒点）→ Copy to Points（复制小盒子）→ Transform 这条链练手，你会立刻体会到「节点串联生成画面」的爽感。

VEX入门：别怕代码

VEX（Vector Expression Language）是Houdini的高性能脚本。你不需要先学编程，只要会几个句式就能做很酷的事。所有VEX写在Attribute Wrangle节点里。

// 让所有点沿Y轴做正弦波动
@P.y += sin(@ptnum * 0.5) * 0.1;

// 按离原点的距离给点上红→蓝色
float d = distance(@P, {0,0,0});
@Cd = set(d, 0, 1 - d);

// 给每个点随机缩放（用于Copy时大小不一）
@scale = rand(@ptnum);

// 隔一个点染成红色（按序号取模）
if (@ptnum % 2 == 0) {
    @Cd = set(1, 0, 0);
}

心智模型：VEX里你写的代码对「每一个元素」自动循环执行。你不用写for循环，Houdini帮你对每个点跑一遍。不想写代码？用VOP把同样的逻辑用节点连线画出来。
