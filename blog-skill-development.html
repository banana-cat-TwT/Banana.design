如何制作自己的Skill

Trae IDE技能开发完全指南

2026年5月7日 阅读: 0 分类: 技术教程

什么是Skill？

Skill是Trae IDE中的扩展功能模块，可以为IDE添加各种自定义功能。通过开发自己的Skill，你可以：

  • 自动化重复任务
  • 集成外部工具和服务
  • 创建个性化的工作流程
  • 分享你的创意和技术给其他用户

现在很多同事和开发者都在制作自己的Skill，这确实是一个很有趣的事情！让我们一起来学习如何创建属于自己的Skill吧！

开发前准备

1. 了解Skill结构

一个标准的Skill包含以下文件：

  • skill.json - Skill的配置文件，定义基本信息
  • index.js - 主入口文件，包含Skill的核心逻辑
  • icon.png - Skill的图标（可选）
  • README.md - 说明文档（可选）

2. 准备开发环境

  • 安装Node.js（推荐最新LTS版本）
  • 熟悉JavaScript/TypeScript基础
  • 了解Trae IDE的Skill API

创建第一个Skill

Step 1: 创建项目文件夹

创建一个新文件夹作为你的Skill项目目录：

mkdir my-first-skill
cd my-first-skill

Step 2: 创建配置文件 skill.json

这是Skill的核心配置文件，定义了Skill的基本信息：

{
"name": "MyFirstSkill",
"displayName": "我的第一个Skill",
"description": "这是我开发的第一个Trae Skill",
"version": "1.0.0",
"author": "你的名字",
"main": "index.js",
"icon": "icon.png",
"commands": [
{
"name": "hello",
"displayName": "打招呼",
"description": "向用户打招呼"
}
]
}

Step 3: 创建主入口文件 index.js

这是Skill的核心逻辑文件：

// 导入Trae Skill API
const { Skill } = require('@trae/skill-sdk');

// 创建Skill实例
const skill = new Skill();

// 注册命令处理函数
skill.onCommand('hello', async (args, context) => {
// 显示一个对话框
await context.showDialog({
title: 'Hello!',
message: '恭喜你创建了第一个Skill!',
buttons: ['确定']
});

// 返回结果
return {
success: true,
message: 'Skill执行成功!'
};
});

// 导出Skill
module.exports = skill;

Step 4: 添加图标（可选）

创建或下载一个PNG格式的图标文件，命名为icon.png，放在项目根目录。

测试你的Skill

方法一：本地测试

  1. 打开Trae IDE
  2. 点击左侧边栏的Skill图标
  3. 选择"加载本地Skill"
  4. 选择你的Skill文件夹
  5. 在命令面板中搜索你的命令名称

方法二：使用开发模式

// 在Skill目录中运行
npm install
npm run dev
提示

开发模式下，修改代码后会自动热更新，无需重新加载Skill。

常用API介绍

对话框API

// 显示消息对话框
await context.showDialog({
title: '标题',
message: '消息内容',
buttons: ['确定', '取消']
});

// 显示输入对话框
const result = await context.showInputDialog({
title: '输入',
message: '请输入内容:',
defaultValue: '默认值'
});

文件操作API

// 读取文件
const content = await context.readFile('/path/to/file.txt');

// 写入文件
await context.writeFile('/path/to/file.txt', '内容');

// 选择文件
const filePath = await context.selectFile({
filters: [{ name: 'JavaScript', extensions: ['js'] }]
});

命令面板API

// 执行IDE命令
await context.executeCommand('workbench.action.files.newFile');

// 显示通知
context.showNotification({
type: 'info', // info, warning, error
message: '操作完成!'
});

实战案例：创建一个代码模板生成器

需求分析

创建一个可以快速生成代码模板的Skill，支持生成常用的代码片段。

实现代码

const { Skill } = require('@trae/skill-sdk');
const skill = new Skill();

// 代码模板库
const templates = {
reactComponent: `import React from 'react';\n\nconst ${name} = () => {\n return (
\n

Hello World

\n
\n );\n};\n\nexport default ${name};`,
expressRoute: `const express = require('express');\nconst router = express.Router();\n\nrouter.get('/', (req, res) => {\n res.json({ message: 'Hello World' });\n});\n\nmodule.exports = router;`
};

skill.onCommand('generateTemplate', async (args, context) => {
const templateType = await context.showInputDialog({
title: '选择模板类型',
message: '请输入模板类型 (reactComponent/expressRoute):'
});

const templateName = await context.showInputDialog({
title: '模板名称',
message: '请输入组件/文件名称:'
});

if (templates[templateType]) {
const content = templates[templateType].replace(/\$\{name\}/g, templateName);
await context.writeFile(`${templateName}.js`, content);
context.showNotification({ type: 'info', message: '模板生成成功!' });
} else {
context.showNotification({ type: 'error', message: '未知模板类型!' });
}
});

module.exports = skill;

发布你的Skill

打包Skill

npm run build

发布到Skill市场

  1. 登录Trae开发者平台
  2. 创建新的Skill发布申请
  3. 上传打包后的Skill文件
  4. 填写Skill信息和描述
  5. 提交审核
注意

发布前请确保你的Skill没有安全漏洞，并且符合Trae的发布规范。

进阶技巧

1. 使用TypeScript

可以使用TypeScript开发Skill，获得更好的类型提示和代码维护性。

2. 集成外部API

Skill可以调用外部API，实现更复杂的功能：

// 使用fetch调用外部API
const response = await fetch('https://api.example.com/data');
const data = await response.json();

3. 持久化存储

使用context.storage保存用户配置：

// 保存配置
await context.storage.set('userConfig', { theme: 'dark' });

// 读取配置
const config = await context.storage.get('userConfig');
