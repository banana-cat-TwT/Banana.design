3ds Max Python脚本：批量统计模型顶点与面数，实现资产初筛

2026年3月27日 - 4月 · 清明假期前后开发

Python 3dsMax脚本 三维管线自动化 AI训练数据预处理

项目背景

项目组采用「总部初加工→外部承包商处理→返回总部」的多环节生产流程，在此过程中遇到了显著的效率瓶颈：

  • 初加工耗时过长：总部的初加工环节本身需要投入大量时间和精力，是整个流程的主要耗时点；
  • 工作负担加剧：团队本身已有繁重的任务量，多环节生产流程的引入进一步增加了工作负担；
  • 个人精力投入过大：初加工环节需要大量个人精力投入，影响工作生活平衡；
  • 效率与质量难以兼顾：在高负荷下，既要保证生产效率，又要维持资产质量，难度较大。

针对上述痛点，设计并实现了这套自动化工具链：一方面通过Python脚本将重复性的资产质检任务自动化，减少人工投入；另一方面制定统一美术规范辅助AI识别2D三视图和3D模型特征，实现AI精准建模，从而有效减少初加工环节的个人精力投入，同时保持生产流程的准确性与效率。

核心目标：建立「自动化初筛+人工精修+AI辅助」的高效流水线，在保持资产质量的前提下，减少初加工环节的个人精力投入。

技术方案设计

本项目包含两个核心部分，分别针对不同的问题场景：

  • 1. 自动化资产质检脚本：基于3ds Max Python API编写脚本，批量遍历目录内三维模型，自动统计顶点量、三角面、四边面数值，并检测模型破面情况，根据自定义阈值快速标记面数超标或存在破面问题的资产；搭配人工精修环节，搭建「脚本初筛+人工精细化拓扑优化」流水线，提升资产质检效率。
  • 2. AI辅助建模规范体系：针对「总部初加工→外部承包商处理→返回总部」多环节生产流程的效率痛点，制定统一美术规范辅助AI识别2D三视图以及3D模型的特征，输出CSV汇总表导入生成平台，实现AI精准建模与批量生成PBR全流程基础模型，有效减少初加工环节的个人精力投入，同时保持生产流程的准确性与效率。

脚本功能清单

  • 1. 批量读取指定文件夹下FBX、OBJ格式模型文件；
  • 2. 统计每个模型总顶点数、三角面数、四边面数；
  • 3. 检测模型破面情况，标记存在拓扑问题的资产；
  • 4. 根据自定义阈值标记面数超标模型；
  • 5. 将统计结果导出CSV报表，方便后续筛选处理与AI平台导入。

开发局限与设计考量

局限1：脚本仅完成参数统计、筛查任务，无法自动重构四边拓扑；强行代码层面做自动四边重拓扑很容易损坏面部、关节等关键区域的细节布线。

局限2：最终采用流水线方案：脚本批量筛出不合格模型，后续借助Max自带ProOptimizer原生减面工具做精细化优化，效果优于纯自研减面代码。

设计考量：明确工具边界，脚本的价值在于「快速筛选」而非「自动修复」，将专业的拓扑优化工作留给人工完成，确保美术质量。这种「工具辅助+人工精修」的分工模式，既保证了效率，又兼顾了产出质量。

AI协作设计：在素材整合阶段，通过制定统一的美术规范辅助AI识别2D三视图特征，输出标准化CSV汇总表导入生成平台，实现AI精准建模。这种「规范引导+数据驱动」的方式，有效提升了AI生成资产的准确度与一致性。

面向AI训练场景的拓展展望

目前正在复刻这套统计逻辑改写Blender Python版本，后续可以用来批量审查AI生成的3D训练素材，批量把控数据集面数规范，适配大模型三维数据预处理的工作需求。

拓展方向：

  • 格式扩展：迁移至Blender Python，支持glTF/FBX等通用格式，覆盖更多3D软件生态；
  • 质检增强：增加UV岛数量、贴图分辨率、LOD层级等质检项，构建完整的资产质量评估体系；
  • AI训练对接：将脚本输出的CSV报表直接对接AI训练数据集预处理流水线，自动过滤不合格素材，提升训练数据质量；
  • 规范迭代：持续优化美术规范文档，提升AI识别2D特征的准确率，实现更精准的AI辅助建模。
