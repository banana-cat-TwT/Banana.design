3ds Max纹理绘制与造型笔刷工具（MaxPaint）

2026年10月 · MaxScript · 3ds Max 2022

MaxScript 3dsMax插件 纹理绘制 造型笔刷 工具开发

由来与设想

这套工具的想法，最早是 2026 年 8 月 1 日跟一些公司提的设想——做一个 BodyPaint 风格的 Max 笔刷工具，把「纹理绘制 + 造型笔刷」整合进 3ds Max，省掉在多个软件之间来回切的麻烦。10 月份把它落地成了 MaxPaint v1.0，一个双面板的 MaxScript 工具，对应早期截图框架复刻而来。

工具定位

MaxPaint 是运行在 3ds Max 2022 里的 BodyPaint 风格工具，把 纹理绘制 和 造型笔刷 两件事合成一个工具，打开后出现两个面板：左边「MaxPaint 绘制面板」、右边「MaxPaint 造型笔刷」。整个工具是一份约 1020 行的 MaxScript（MaxPaint.ms），拖进视口或 Scripting > Run Script 即可运行。

必须在 Max 主界面内运行，不要用 3dsmaxbatch 后台跑（会触发激活弹窗）。

左面板：纹理绘制

  • 纹理：新建纹理（标准材质 + 1024 PNG）、输入纹理、UV 展开、UV 盒贴图、保存 / 另存为 / 打开目录 / 结束编辑；
  • 笔刷：贴图绘制 / 顶点色两种模式；大小（像素）、不透明度、硬度可调；软边 / 硬边 / 喷溅三种笔头；支持只画可见面、显示顶点色；
  • 颜色：拾色器、前景 / 背景互换、黑 / 白快捷键；
  • 版本：纹理快照，保存 / 恢复 / 删除版本（PNG 文件副本）。

右面板：造型笔刷

  • 笔刷模式：推拉（抓取拖动改轮廓体积）/ 平滑 / 鼓起压低（Ctrl 反向）；
  • 参数：固定笔刷大小、大小（世界单位）、力度、渐变（中心 100% 到边缘 0%）；
  • 选区：仅编辑选中部分、冻结选中 / 清除冻结；
  • 对称：启用对称 + X / Y / Z 轴 + 中心坐标（默认取对象轴心）；
  • 撤销：Max 原生 Ctrl+Z / Ctrl+Y，外加撤销历史滑条（最近 22 步，可拖动回退）；
  • 快照：模型快照，保存 / 恢复 / 清空；
  • 布局：停靠左 / 停靠右 / 浮动 / 双列。

视口内左键按住拖动即笔刷生效（推拉是点击抓住表面后拖动）；右键 / Esc 退出笔刷；Shift 临时切平滑，Ctrl 在鼓起压低时反向；视口内黄色圆圈是笔刷范围预览。

关键实现

  • 造型笔刷：推拉用「点击抓取 + 视图平面 delta 抓取权重列表」，平滑用邻接平均，鼓起压低沿顶点法线（Ctrl 反向），配渐变指数 falloff；对称采用「双 pass 镜像中心 / 镜像 delta」，冻结 / 仅编辑选中用 bitArray 蒙版控制。
  • 纹理绘制：基于 dotNet System.Drawing 的 Bitmap + Graphics，按 UV 重心插值落点，软边 / 硬边 / 喷溅笔头，PNG 存储后用 BitmapTexture 重建刷新视口；顶点色绘制走 polyop.setVertColor。
  • 停靠布局：用 dotNet Screen.WorkingArea 配合 GetDialogSize / SetDialogPos 实现左 / 右 / 浮动 / 双列四档布局。

已知限制

  • 纹理以 PNG 存储（Max 无法纯脚本写 PSD，PS 可直接打开 PNG 再转）；
  • PSD 图层、红色蒙版选区等高级功能未实现；
  • 大模型（10 万面以上）笔刷会有卡顿，建议先减面测试；
  • 自动 UV 展平依赖 Unwrap UVW 接口，个别版本签名不同会提示手动操作。
