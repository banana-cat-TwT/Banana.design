一、研究概述

今天花了一点时间初步了解了 Cocos Creator 这款游戏引擎编辑器。完整走通了「下载编辑器 → 登录账号 → 新建项目」的流程，并梳理了新建项目时编辑器提供的模板与案例体系。本篇为系列研究日志的第一篇，主要记录编辑器开箱即用的项目模板与案例分布，后续会补充每个模板/案例下载后的实际内容。

研究动机：Cocos 在 2D/3D 轻量级游戏、小游戏、跨平台发布方面应用广泛，作为多引擎对比研究的一部分，先从编辑器自带的项目模板切入，快速建立对其能力边界的整体认知。

三、模板与案例清单

点击「新建项目」后，编辑器会呈现两大类资源：模板（空白起点项目）与案例（带完整内容的示例项目）。

3.1 模板（Templates）

模板是新建项目的起点，按维度分类提供空白工程骨架：

模板类型说明
3D 模板三维面向 3D 项目的空白起点工程
2D 模板二维面向 2D 项目的空白起点工程
AR/VR 模板扩展现实面向 AR、VR 项目的空白起点工程

3.2 案例（Examples）

案例是带完整内容的示例项目，可用于学习参考：

案例类型说明
3D 案例三维3D 场景示例
2D 案例二维2D 场景示例
2D UI 案例二维界面2D 界面/UI 示例
3D 基础角色 ×2三维角色两个 3D 基础角色示例
AR 案例扩展现实增强现实示例
VR 案例扩展现实虚拟现实示例
初步观察：Cocos Creator 自带的项目模板覆盖了 3D / 2D / AR·VR 三大方向，案例则进一步细分为场景级、UI 级、角色级、AR/VR 级，体系较为完整。对快速了解引擎能力边界、以及作为学习入口非常友好。

四、初步心得

  • 开箱即用的案例体系：新建项目即能看到分门别类的模板与案例，降低了上手门槛，不必从零摸索
  • 2D/3D/AR·VR 全覆盖：一套引擎覆盖多种维度，对跨品类创作比较友好
  • 案例即教程：3D 基础角色、2D UI 等案例可直接作为学习样本，比单纯看文档更直观
  • 后续需验证的点：模板下载后的工程结构、案例的实际运行效果、以及与 Unity 等引擎的工作流差异，需在下一篇日志中展开
