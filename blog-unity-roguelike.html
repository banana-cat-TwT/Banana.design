BSP算法原理

BSP算法是一种空间划分算法，它通过递归地将空间分割为更小的子空间来创建地图。具体步骤如下：

  1. 从一个初始的大空间开始
  2. 随机选择一个方向（水平或垂直）
  3. 在随机位置分割空间
  4. 对每个子空间重复上述过程，直到达到最小空间大小

代码实现

public class BSPGenerator {
    public class Node {
        public RectInt rect;
        public Node left;
        public Node right;
        public bool isLeaf;
    }

    public static Node Generate(int width, int height, int minSize) {
        Node root = new Node {
            rect = new RectInt(0, 0, width, height),
            isLeaf = true
        };

        SplitNode(root, minSize);
        return root;
    }

    private static void SplitNode(Node node, int minSize) {
        if (!node.isLeaf) return;

        // 决定分割方向
        bool splitHorizontal = Random.value > 0.5f;
        if (node.rect.width > node.rect.height && node.rect.width / node.rect.height > 1.25f) {
            splitHorizontal = false;
        } else if (node.rect.height > node.rect.width && node.rect.height / node.rect.width > 1.25f) {
            splitHorizontal = true;
        }

        int max = splitHorizontal ? node.rect.height - minSize : node.rect.width - minSize;
        if (max <= minSize) return;

        int splitPos = Random.Range(minSize, max);
        if (splitHorizontal) {
            node.left = new Node {
                rect = new RectInt(node.rect.x, node.rect.y, node.rect.width, splitPos),
                isLeaf = true
            };
            node.right = new Node {
                rect = new RectInt(node.rect.x, node.rect.y + splitPos, node.rect.width, node.rect.height - splitPos),
                isLeaf = true
            };
        } else {
            node.left = new Node {
                rect = new RectInt(node.rect.x, node.rect.y, splitPos, node.rect.height),
                isLeaf = true
            };
            node.right = new Node {
                rect = new RectInt(node.rect.x + splitPos, node.rect.y, node.rect.width - splitPos, node.rect.height),
                isLeaf = true
            };
        }

        node.isLeaf = false;
        SplitNode(node.left, minSize);
        SplitNode(node.right, minSize);
    }
}

房间连接技术

生成BSP树后，我们需要为每个叶子节点创建房间，并连接相邻的房间。具体步骤如下：

  1. 为每个叶子节点创建一个随机大小的房间
  2. 遍历BSP树，连接相邻的房间
  3. 创建走廊连接这些房间

代码实现

public class RoomGenerator {
    public static List<RectInt> GenerateRooms(Node root) {
        List<RectInt> rooms = new List<RectInt>();
        CollectRooms(root, rooms);
        return rooms;
    }

    private static void CollectRooms(Node node, List<RectInt> rooms) {
        if (node.isLeaf) {
            // 创建随机大小的房间
            int roomWidth = Random.Range(4, node.rect.width - 1);
            int roomHeight = Random.Range(4, node.rect.height - 1);
            int roomX = node.rect.x + Random.Range(1, node.rect.width - roomWidth);
            int roomY = node.rect.y + Random.Range(1, node.rect.height - roomHeight);
            rooms.Add(new RectInt(roomX, roomY, roomWidth, roomHeight));
        } else {
            CollectRooms(node.left, rooms);
            CollectRooms(node.right, rooms);
        }
    }

    public static void ConnectRooms(List<RectInt> rooms) {
        // 连接相邻的房间
        for (int i = 0; i < rooms.Count - 1; i++) {
            ConnectTwoRooms(rooms[i], rooms[i + 1]);
        }
    }

性能优化

随机地图生成可能会消耗大量计算资源，特别是在生成大型地图时。以下是一些性能优化技巧：

  • 限制递归深度：避免过深的递归，设置最大分割次数
  • 使用对象池：重用节点和房间对象，减少内存分配
  • 并行计算：在支持的平台上使用多线程生成地图
  • 缓存结果：缓存常见大小的地图，避免重复计算

结论

通过BSP算法和房间连接技术，我们可以创建出多样化的随机地图，为Roguelike游戏提供无限的可玩性。结合性能优化技巧，即使在复杂的游戏场景中，也能实现流畅的地图生成体验。
